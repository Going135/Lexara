UNDER THE HOOD蜘蛛是算出来的，不是画出来的

没有 sprite sheet，没有骨骼动画文件。八条腿每一帧都由几何解算出来 —— 上面演示里的那八条腿也是同一套算法。

两骨 IK + 阈值步态

每条腿是髋 → 膝 → 脚尖两段骨。膝盖位置由两圆交点解出，骨长和值 L1 + L2 = 1.26 × reach。脚钉在原地，体心相对静止位偏移超过阈值才迈步，迈步时脚向髋部收 18%（真抬腿）。

在阈值骨架之上叠加了异步行波相位排班，八条腿像波浪一样依次迈步，而不是各自独立触发。

落脚点严格是「静止位 + 速度前瞻」，没有随机抖动 —— 加了抖动，脚会在原地游走，站姿散成一团。

为什么不用 Web 技术栈

桌宠需要「全透明 + 置顶 + 区域穿透点击 + 60fps 自绘」。套一层 WebView 来做这件事，比 QPainter 逐帧自绘贵得多，打包时还要多塞几十 MB。

所以：Qt Widgets 画桌宠与瞄准层（自绘 + 区域遮罩更稳），QML 做启动台，OCR 是纯 ONNX，词典是只读 SQLite，threading.local 管连接，不阻塞 UI。

PRIVACY截图不出这台机器

没有账号、没有云同步、没有遥测 —— 整份程序里没有任何上报端点。

  • 截图不落盘：框选的是本机屏幕，OCR 在本机模型上跑，识别完的临时图直接丢掉
  • 词典内置：ECDICT Revised，758,497 条，只读，随包分发
  • 不需要联网激活：装上就能用，没有登录墙
  • AI 是可选的：只有你点了「AI 语境」才发请求，且只发词 + 词典义项 + 相邻句，永不发送截图
  • 不做：多用户 / 云同步 / 账号体系
  • 不做：移动端、macOS、Linux（大量 Windows 专有 API：全局鼠标钩子、DPI 换算、DPAPI、Startup 目录）
  • 没做完：持续自动扫描（帮助面板里如实标着「规划中」）
  • 没做完：拼写 / 听力题型，目前只有「看词回忆 + 自评」

上面那栏是刻意写出来的：「看起来能点」不等于「功能完整」。写清楚边界，比多写三个特性更值得信任。

GET IT两条路，都不需要账号

路线 A 只想用：下 exe 双击。路线 B 想改代码：Python 3.13 从源码跑。仓库里是纯源码，exe 作为 Release 附件提供。

路线 A · 直接运行

下载 Lexara.exe（约 150 MB），双击即可。不需要装 Python，不需要装运行库。

首次启动会先把内部文件（含 75.8 万条词典）解压到临时目录，约 10~20 秒，之后再启动就快了。

没买代码签名证书，首次可能弹「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。

系统要求：Windows 10 / 11 64 位 · 不需要管理员权限 · 不写注册表

路线 B · 从源码跑

前置：Python 3.13（64 位）。双击 install_first.bat 建环境装依赖，再双击 run.bat 启动，启动台里点「部署」。

依赖只有 6 个：PySide6-Essentials、shiboken6、rapidocr_onnxruntime、onnxruntime、opencv-python、numpy。

想自己打包：python -m PyInstaller Lexara.spec，产物在 dist\Lexara.exe。仓库里 5 份 spec，结构一致。

卸载 = 删掉 exe，再删 %APPDATA%\Lexara 整个目录
