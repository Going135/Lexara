# 框选中译英

按 **Ctrl+Alt+T**，或右键桌宠 → **框选中译英（AI）** → 框住中文。结果卡显示中文原文和英文译文，支持修改原文后重译、重试、复制和关闭。Esc / 右键取消框选。快捷键在 Windows 全局生效；被其他程序占用时，仍可通过菜单或 Lexara 内的快捷键进入。

先在启动台「设置 → AI 模型」配置 Base URL、模型名称和 API Key。翻译复用现有配置与 Windows DPAPI 密钥存储。未配置时保留本机识别的原文并显示配置引导。

## 实现

- 复用冻结截图、选区与 DPR 换算；翻译卡按选区所在屏幕的可用区域定位。
- 中文识别固定使用随包提供的中英文 RapidOCR 整图检测，不套用英文识词的行带裁剪，保留中文换行后的短行；不改变英文识词的引擎设置。
- `src/ai/translation.py` 按行坐标整理文字，合并普通折行，保留标题、列表及明显的段落间隔。独立翻译提示词不携带聊天历史或学习人设；一次最多 4000 个原文字符。
- 不再静默丢弃低置信度行。置信度低于 `max(0.8, 用户最小置信度)` 的文字标黄并进入复核状态，用户核对后点击「确认并翻译」，此前不发送模型请求。
- 支持 SSE 流式显示，分别显示识别和翻译的等待时间。兼容服务直接返回普通 JSON；仅在明确拒绝 `stream` 参数时降级重试一次，鉴权等错误不重试。连接中断或 token 截断不能冒充翻译成功，未完成译文不启用复制按钮。
- 仅发送识别后的原文，不发送截图、词典、单词本或聊天记录。翻译不会新增单词本记录，也不参与八腿选词队列。
- OCR 与 HTTP 均在后台运行，结果通过 GUI 线程中的接收对象交给界面。关闭、重选、重译后作废旧请求；实际计算/网络调用在返回或超时后回收，不能保证服务端停止处理已发送的请求。
- 翻译卡可见时暂停自由移动和桌面感应抓屏，关闭后恢复。收回桌宠与退出应用时等待线程结束再清理对象。

## 验证

```text
python test/test_translation.py
python tools/translation_probe.py
python tools/qml_smoke.py
```

`test_translation.py` 包含 24 项测试，涵盖文字整理、低置信度复核、emoji 后的高亮定位、输入限制、独立提示词、配置失败、空响应/截断、JSON/SSE 与降级、过期结果、编辑/复制/关闭、150% DPR 与负屏幕坐标、独立全局快捷键及注销、桌宠接线与感应暂停，以及真实后台 HTTP 请求与 GUI 线程交付。

`translation_probe.py` 使用真实 RapidOCR 1.2.3 识别合成中文截图，再调用本机模拟翻译接口并生成翻译卡预览；不调用外部模型。输出位于忽略目录 `.tmp-shot/translation-source.png` 和 `.tmp-shot/translation-preview.png`。

网页、PDF、聊天排版样本的真实模型验收见 [验收报告](translation-acceptance.md)。`tools/translation_acceptance.py --prepare` 生成自建样本，网页和聊天 HTML 用浏览器截图；`--live --label <name>` 仅发送这些测试文字到已配置的服务，报告保存在 `.tmp-shot/translation-acceptance/`。

原 `.venv` 在获得本机访问权限后已确认可用：Python 3.13.15、Qt 6.12.0、RapidOCR 1.2.3。早期将受限运行失败判断为解释器缺失不准确；本轮回归与体验版均使用原环境，项目依赖清单未修改。实体混合 DPI 多屏设备仍未验证，坐标检查使用模拟选区。
