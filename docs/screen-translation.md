# 框选中译英

右键桌宠 → **框选中译英（AI）** → 框住中文。结果卡显示中文原文和英文译文，支持修改原文后重译、重试、复制和关闭。Esc / 右键取消框选。

先在启动台「设置 → AI 模型」配置 Base URL、模型名称和 API Key。翻译复用现有配置与 Windows DPAPI 密钥存储。未配置时保留本机识别的原文并显示配置引导。

## 实现

- 复用冻结截图、选区与 DPR 换算；翻译卡按选区所在屏幕的可用区域定位。
- 中文识别固定使用随包提供的中英文 RapidOCR，不改变英文识词的引擎设置；当前 Paddle 配置仅支持英文。
- `src/ai/translation.py` 按行坐标整理文字，合并普通折行并保留明显的段落间隔。独立翻译提示词不携带聊天历史或学习人设；一次最多 4000 个原文字符。
- 仅发送识别后的原文，不发送截图、词典、单词本或聊天记录。翻译不会新增单词本记录，也不参与八腿选词队列。
- OCR 与 HTTP 均在后台运行，结果通过 GUI 线程中的接收对象交给界面。关闭、重选、重译后作废旧请求；实际计算/网络调用在返回或超时后回收，不能保证服务端停止处理已发送的请求。
- 翻译卡可见时暂停自由移动和桌面感应抓屏，关闭后恢复。收回桌宠与退出应用时等待线程结束再清理对象。

## 验证

```text
python test/test_translation.py
python tools/translation_probe.py
python tools/qml_smoke.py
```

`test_translation.py` 包含 15 项测试：文字整理、输入限制、独立提示词、配置失败、空响应/截断、重试、过期结果、编辑/复制/关闭、150% DPR 与负屏幕坐标、桌宠接线与感应暂停，以及真实后台 HTTP 请求与 GUI 线程交付。

`translation_probe.py` 使用真实 RapidOCR 1.2.3 识别合成中文截图，再调用本机模拟翻译接口并生成翻译卡预览；不调用外部模型。输出位于忽略目录 `.tmp-shot/translation-source.png` 和 `.tmp-shot/translation-preview.png`。

本次相关回归通过：英文识词、连续扫描、OCR 坐标与线程、瞄准层、AI 辅助、人设、模型配置加密、桌宠生命周期与桌面感应。QML 启动台冒烟检查通过。

原 `.venv` 指向的 Python 3.13 基础解释器已缺失，本次在独立 Python 3.12.14 环境验证，Qt 6.12.0、RapidOCR 1.2.3；项目依赖清单与原环境未修改。尚未验证外部模型译文质量、实体混合 DPI 多屏设备或新 exe 打包；坐标检查使用模拟选区。
